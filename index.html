เรียนรู้ VS Code, XAMPP, โครงสร้างไฟล์ และการทำงานของเว็บเซิร์ฟเวอร์

จุดประสงค์เครื่องมือเว็บเซิร์ฟเวอร์ติดตั้งโครงสร้างไฟล์ลงมือทำแบบทดสอบใบงาน

VS Code

ดาวน์โหลด VS Code

XAMPP

ชุดเครื่องมือจำลองเซิร์ฟเวอร์ มี Apache, MariaDB และ PHP

ดาวน์โหลด XAMPP

เว็บเบราว์เซอร์

Chrome, Edge หรือ Firefox ใช้เปิดหน้าเว็บและตรวจสอบผลลัพธ์

🌐 เว็บเซิร์ฟเวอร์ทำงานอย่างไร?

🖥️ Browser→ คำขอ HTTP →🗄️ Apache / XAMPP→ ส่งผลลัพธ์ →🖥️ Browser
  1. ผู้ใช้เปิด http://localhost/mywebsite/
  2. เบราว์เซอร์ส่ง HTTP Request ไปยัง Apache บนเครื่องเดียวกัน
  3. Apache ค้นหาไฟล์เว็บไซต์ หากเป็น PHP จะประมวลผลฝั่งเซิร์ฟเวอร์
  4. Apache ส่ง HTTP Response กลับไปยังเบราว์เซอร์
  5. เบราว์เซอร์แสดง HTML/CSS และเรียกใช้ JavaScript

จำง่าย: localhost หมายถึงเครื่องคอมพิวเตอร์ที่กำลังใช้งานอยู่ (โดยทั่วไปคือ 127.0.0.1) และ XAMPP เหมาะสำหรับพัฒนาและทดสอบภายในเครื่อง ไม่ควรเปิดเซิร์ฟเวอร์ทดสอบสู่สาธารณะโดยไม่มีการตั้งค่าความปลอดภัย

⚙️ วิธีติดตั้งทีละขั้น

ติดตั้ง VS Code

  1. ดาวน์โหลดจากเว็บไซต์ทางการ
  2. เปิดไฟล์ติดตั้งและทำตามขั้นตอนบนหน้าจอ
  3. เปิด VS Code แล้วเลือก File → Open Folder
  4. เลือกโฟลเดอร์สำหรับเก็บงานเว็บไซต์

ติดตั้ง XAMPP

  1. ดาวน์โหลด XAMPP สำหรับ Windows จากเว็บไซต์ทางการ
  2. ติดตั้งไว้ที่ C:\xampp (หากใช้ตำแหน่งอื่นให้ปรับเส้นทางตามจริง)
  3. เปิด XAMPP Control Panel แล้วกด Start ที่ Apache
  4. เปิดเบราว์เซอร์ไปที่ http://localhost/ เพื่อตรวจสอบ

หาก Apache เปิดไม่ขึ้น ให้ตรวจสอบว่าพอร์ต 80 หรือ 443 ถูกโปรแกรมอื่นใช้งานหรือไม่

📁 โครงสร้างไฟล์เว็บไซต์

coffee-shop/
├── index.html       # หน้าแรก
├── about.html       # เกี่ยวกับร้าน
├── contact.html     # ติดต่อร้าน
├── css/
│   └── style.css    # รูปแบบหน้าเว็บ
├── js/
│   └── script.js    # การโต้ตอบ
└── images/
    └── coffee.jpg   # รูปภาพ

HTML = เนื้อหาและโครงสร้าง · CSS = การตกแต่ง · JavaScript = การโต้ตอบ · PHP = การประมวลผลฝั่งเซิร์ฟเวอร์

👨‍💻 กิจกรรม: เว็บไซต์แรกของฉัน

  1. สร้างโฟลเดอร์ C:\xampp\htdocs\mywebsite
  2. เปิดโฟลเดอร์นี้ใน VS Code แล้วสร้างไฟล์ index.html
  3. คัดลอกโค้ดตัวอย่างด้านล่างและบันทึกไฟล์ (Ctrl+S)
  4. เปิด Apache ใน XAMPP
  5. เข้า http://localhost/mywebsite/ แล้วทดสอบปุ่ม
